# Instruções

## Criar novo Post
```
> ./novo-post.sh "Como funciona o Spring Boot" "java,spring-boot"
```

## renomear arquivo com base no novo título
```
> ./renomear-post.sh como-funciona-o-spring-boot "Como o Spring Boot funciona por dentro"
```

## rodar servidor
como em prd:
```
> hugo server
```

em modo draft:
```
> hugo server -D
```
